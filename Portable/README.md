# Grimlock Portable

**Grimlock Portable** is a distributable AI assistant derived from the original Grimlock project. It allows you to run the app on any compatible system without local development dependencies.

## Key Features
- Lightweight, modular AI assistant  
- Portable: self-contained folder with relative memory/log paths  
- Configurable LM Studio backend connection  
- Automatic dependency installation via bootstrap script  

## Usage Notes
- Some advanced development-only features are disabled in this portable edition for safe distribution.  
- Intended for personal, educational, or research purposes only.  

## Identity & Vision
Grimlock Portable is designed to make the AI assistant easily shareable while maintaining controlled functionality and user safety.
